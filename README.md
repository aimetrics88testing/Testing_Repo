# ShopEase

React + Vite e-commerce demo for [Testing_Repo](https://github.com/aimetrics88testing/Testing_Repo).

## Features

- Header with Products dropdown, Customer Care, Cart, and Profile
- Category browsing (Electronics, Women dresses, Men dresses, Daily essentials, Beauty products)
- Add to cart with quantity controls and subtotal
- Responsive storefront layout with footer

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite (usually http://localhost:5173/).
